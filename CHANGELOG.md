# Changelog

## 0.1.0 - 2026-11-12

First tagged release.

- 46 tools across Find jobs, Resume, Reach out, Interview, Offer, Join and leave, At work, Grow and Just for fun.
- Career Vault: resume import, profile review and versions, stored in the browser (IndexedDB).
- Grounded output: citations to vault chunks, invented skills and figures removed or flagged, adversarial review pass.
- Apply to this job: agent workflow with budgets and gates (bring your own key).
- Free tier: one run a day on Groq with sign-in, with model-by-model failover through Groq and Gemini.
- Free tier model moved to `openai/gpt-oss-120b` after Groq retired `llama-3.3-70b-versatile`.
