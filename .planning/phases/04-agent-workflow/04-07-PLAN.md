    Loop `advance()`: guard with a ref so double clicks never double-run; compute localNextAction(record): "gate" -> status awaiting_approval, render GateBar in the active card, focus its heading, announce; "stop" -> RunBanner; "complete" -> completed state; "step" -> mark the active card running, POST /api/agent/step with buildStepRequest(record, {chunks, profile (non-empty fields only), config: access.requestConfig, semanticOrder for the outreach query}), signal from the abort controller. After every gate action (approveGateA, rerunFitCheck after editing JD/notes with the visible note "Cleared because the fit check changed", overrideSkip after confirmation, approveGateB/declineOutreach, stopRun after confirmation, continueWithNewBudget, saveArtifactEdit/revertArtifactEdit) call saveAgentRun then advance() where appropriate. "Pause after this step" checkbox (default off) sets record.pauseAfterStep. Show "Saved to your Career Vault {time}" (Label style, --faint) in the aside; silent saves never move focus. "Continue with a new budget" is offered only when access is BYOK or remaining >= 1 and budget.resets < AGENT_MAX_BUDGET_RESETS.
