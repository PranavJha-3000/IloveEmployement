## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process env / .env -> harness | Secret API keys enter the process |
| harness -> provider API | Keys sent over HTTPS; responses are untrusted |
| harness -> disk (evals/results) | Cache and transcripts persist provider output |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Information disclosure | env.ts / models.ts | mitigate | Keys only in memory and request headers; describeConfig prints "key: set"; model listing uses x-goog-api-key header so keys never appear in URLs or logged errors; tests assert a fake key is absent from all output |
| T-03-05 | Information disclosure | cache.ts / recordingModel.ts | mitigate | Cache entries store only text, toolCalls, usage, finishReason, thoughtsTokens, modelVersion; never headers, rawResponse or request bodies; errors pass through redactSecrets; cache under gitignored evals/results/ |
| T-03-06 | Denial of service (quota exhaustion) | throttle.ts | mitigate | Per-model RPM spacing, bounded exponential backoff (max 5 attempts, 60 s cap), Retry-After honoured, per-day 429 aborts immediately, SDK retries neutralised by rethrowing plain Errors, estimator before every run |
| T-03-07 | Tampering | cache.ts | mitigate | Atomic tmp+rename writes; corrupt or version-mismatched entries are misses, not trusted data |
</threat_model>
