<objective>
Grow the behavioural eval case set from the existing 10 cases to 28 cases across all six engines, with adversarial tags, and make case preparation deterministic so the generation cache can key on prompt hashes.

Purpose: LEVAL-06. The cases must be authored and committed before any real-model run (Plan 08), so the numbers cannot be tuned to the cases afterwards. Deterministic chunk ids matter because `chunkResume` assigns random ids on every call; without stable ids every prompt hash changes and the disk cache never hits, which would burn free-tier quota on every resume.
Output: extended evals/cases.ts, evals/llm/caseRun.ts, evals/llm/fingerprint.ts, tests/llm-cases.test.ts.
</objective>
