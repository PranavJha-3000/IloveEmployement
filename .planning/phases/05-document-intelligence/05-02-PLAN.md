<interfaces>
Contracts this plan creates (Plan 13 imports these exact names):
- type DiffOp<T> = { op: "equal" | "insert" | "delete"; items: T[] }
- diffSequences<T>(a: T[], b: T[], eq?: (x: T, y: T) => boolean): DiffOp<T>[]
- type WordSegment = { text: string; changed: boolean }
- diffWords(from: string, to: string): { from: WordSegment[]; to: WordSegment[] }
- normalizeResumeLines(text: string): string[]
- type DiffRow =
    | { type: "context"; text: string }
    | { type: "added"; text: string }
    | { type: "removed"; text: string }
    | { type: "changed"; from: WordSegment[]; to: WordSegment[]; changeIndex: number }
    | { type: "collapsed"; count: number; lines: string[] }
  (added/removed rows also carry changeIndex: number so "Previous/Next change" can navigate)
- interface ResumeDiff { rows: DiffRow[]; counts: { added: number; removed: number; changed: number }; identical: boolean; changeCount: number }
- buildResumeDiff(fromText: string, toText: string, opts?: { context?: number; collapseOver?: number }): ResumeDiff   // defaults context 3, collapseOver 6
</interfaces>

<feature>
  <name>Resume version diff</name>
  <files>lib/diff.ts, tests/diff.test.ts</files>
  <behavior>
    - diffSequences(["a","b","c"], ["a","x","c"]) yields equal[a], delete[b], insert[x], equal[c] (delete before insert within a replace)
    - diffSequences([], ["a"]) is a single insert; diffSequences(["a"], []) a single delete; both empty -> []
    - normalizeResumeLines("- Led team  \r\n\r\n\r\n* Shipped") === ["• Led team", "", "• Shipped"]: CRLF -> LF, trailing whitespace trimmed, internal whitespace runs collapsed to one space, a leading bullet glyph from the set • ● ▪ ◦ ‣ ∙ · - – — * (followed by whitespace) becomes "• ", runs of blank lines collapse to one, leading and trailing blank lines dropped
    - buildResumeDiff(x, x) -> identical true, counts {0,0,0}, rows contain no added/removed/changed
    - buildResumeDiff("- a\n- b", "• a\n• b") -> identical true (formatting-only)
    - A replaced line ("• Cut latency by 30%" -> "• Cut p99 latency by 30%") is one "changed" row; diffWords marks only "p99" plus its separating space as changed on the to side, and the from side has no changed segments
    - A run of 3 deleted lines followed by 2 inserted lines yields 2 changed rows then 1 removed row; counts = { added: 0, removed: 1, changed: 2 }
    - 20 unchanged lines between two changes collapse to: 3 context, one collapsed row with count 14 and the 14 lines, 3 context
    - Unchanged lines at the start or end beyond 3 lines from the nearest change collapse too; a run of exactly 6 unchanged lines is not collapsed
    - changeIndex increments per change group (a changed/added/removed block contiguous in the diff counts as one group) and changeCount equals the number of groups
    - Performance guard: two 2,000-line texts differing in 10 lines build in under 500 ms (measured with performance.now in the test)
    - One side empty string: every line of the other side is added (or removed); identical false
  </behavior>
  <implementation>
    lib/diff.ts: implement `diffSequences` with the Myers O((N+M)D) greedy algorithm (forward pass storing the V array per d for backtracking, then backtrack into op runs; merge adjacent ops of the same kind; emit delete before insert inside a replacement). `diffWords` tokenizes each side with split on /(\s+)/ (keeping whitespace tokens), runs diffSequences on tokens, and marks tokens changed when they are in a delete (from side) or insert (to side); adjacent segments with the same changed flag are merged. `buildResumeDiff` normalizes both texts with normalizeResumeLines, diffs lines, pairs each delete run with the immediately following insert run index by index (pairs become "changed" rows, leftovers become removed/added rows), assigns changeIndex per contiguous change group, then applies the collapse rule (equal runs longer than collapseOver become context-before (3) + collapsed + context-after (3); leading/trailing equal runs keep only the side adjacent to a change). If both sides normalize to identical arrays, return identical true with rows = all lines as context (the UI shows the identical message instead). No DOM, no React, no imports.
  </implementation>
</feature>
