    - "@30" strategies are never adopted, even when they would pass every check

      R1 (rerank adoption). Candidates are hybrid+rerank and embeddings+rerank, each reranking the top 20 candidates of its base ranking. The top 30 rows are sensitivity rows and cannot be adopted. Independently of R1, the app's default (no reranker) mode switches from hybrid to embeddings-only only if embeddings' overall ndcg@8 is strictly greater than hybrid's and the lower bound of the 95% CI of the paired delta embeddings minus hybrid is strictly greater than 0. Otherwise the app stays on hybrid (no change without evidence).

    evals/retrieval/stats.ts:
    - mulberry32(seed: number): () => number (standard 32-bit mulberry32).
    - pairedBootstrapCI(deltas: number[], opts?: { iterations?: number; seed?: number; confidence?: number }): { mean: number; lo: number; hi: number }. Defaults iterations 10000, seed 20261031, confidence 0.95. For each iteration draw n indices with Math.floor(rand() * n) from one PRNG seeded once per call, compute the resample mean; sort the B means ascending; with alpha = 1 - confidence, lo = sorted[Math.floor((alpha / 2) * B)] and hi = sorted[Math.ceil((1 - alpha / 2) * B) - 1]. mean is the plain mean of deltas. Throw on empty input or non-finite values. Write the same index definition into DECISION.md's Statistics section.
