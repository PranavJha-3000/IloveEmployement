<objective>
Define the typed profile contract, its validation rules and the code-computed confidence that every producer (deterministic extractor, LLM refinement finalizer), consumer (review UI, metrics) and store (IndexedDB, import) shares.

Purpose: DOC-01 requires a typed, validated profile with per-field confirm/correct. The user decision is that confidence is computed in code, never self-reported by a model. Defining this contract first lets the gold dataset (Plan 06) be authored without seeing the extractor.
Output: lib/profile/schema.ts, lib/profile/confidence.ts, lib/profile/sync.ts, tests/profile-schema.test.ts.
</objective>

Contracts this plan creates (later plans import these exact names):
- YearMonthSchema = z.object({ year: z.number().int().min(1950).max(2100), month: z.number().int().min(1).max(12).nullable() })
- ContactSchema { name, email, phone, location: string; links: string[] }
- RoleSchema { title, company, location: string; start: YearMonth | null; end: YearMonth | null; current: boolean; bullets: string[] }
- EducationSchema { degree, institution, detail: string; startYear: number | null; endYear: number | null }
- SkillSchema { name: string; canonicalId: string | null; matchedFrom: string[] }
- ProjectSchema { name, description, link: string; skills: string[] }
- StructuredProfileSchema { contact, roles, education, skills, projects }; type StructuredProfile
- type FieldPath = string  // "contact.name", "contact.links.0", "roles.2.start", "roles.2.bullets", "education.0.endYear", "skills.3", "projects.1.name"
- interface ExtractionResult { profile: StructuredProfile; confidence: Record<FieldPath, number>; method: "deterministic" | "refined"; sourceHash: string; warnings: string[] }
- ConfirmedProfileSchema { profile: StructuredProfile; confirmedAt: number; sourceHash: string; method: "deterministic" | "refined" }; type ConfirmedProfile
- LOW_CONFIDENCE_THRESHOLD = 0.8
- CONFIDENCE = { grounded: 1, ungrounded: 0.4, invalid: 0.3, missing: 0 }
- emptyProfile(): StructuredProfile
- fieldPaths(p: StructuredProfile): FieldPath[]
- validateProfile(p: StructuredProfile, now?: Date): Record<FieldPath, string>
- groundingText(s: string): string; isGrounded(value: string, sourceNorm: string): boolean; dateGrounded(d: YearMonth, sourceLines: string[]): boolean
- computeConfidence(p: StructuredProfile, sourceText: string): Record<FieldPath, number>
- needsLookCount(confidence: Record<FieldPath, number>): number
- toVaultProfile(p: StructuredProfile, existing: VaultProfile): VaultProfile
- applyQuickProfile(p: StructuredProfile, quick: VaultProfile): StructuredProfile
</interfaces>
